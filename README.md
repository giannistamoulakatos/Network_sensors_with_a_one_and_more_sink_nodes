## Περιγραφή
Πρόκειται για μια εργασία στην οποία έχουμε δημιουργήσει αρχικά ένα κόμβο sink για να στέλνουμε δεδομένα όλων των κόμβων και στην συνέχεια δημιουργήσαμε και άλλους κόμβους sink για να στέλνουμε τα δεδομένα ολων των κόμβων εκτός των κόμβων που είναι sink.

## Στόχος
Στόχος τις εργασίας είναι να δούμε πως επιρεάζεται ο αριθμός των μεταδόσεων ανάλογα με πόσους κόμβους sink έχουμε.Στην πρώτη περίπτωση έγινε με ένα κόμβο sink και στην δεύτερη με περισσότερους κόμβους sink.
